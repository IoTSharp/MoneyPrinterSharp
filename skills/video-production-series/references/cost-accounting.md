# 成本核算口径

## 记录规则

- 以供应商稳定 `task_id` 去重，同一任务的 submit、poll 和 download 只计一次。没有任务号的同步请求使用供应商请求 ID 或本地幂等 ID，并说明依据。
- 金额保留原币种和原始精度；CNY、USD 等分别小计。没有可验证汇率时不折算，不把不同币种直接相加。
- 未知费用写 `null`，不要写 0。0 表示已确认免费，`null` 表示缺少账单或计价依据。
- 估算与实际分列。超时、网络断开或本地取消后，外部任务仍可能执行和扣费，状态未核实时保持待定。
- 汇总表列出种类、供应商、模型、任务号、数量/时长、单价依据、估算、实际、币种和是否已包含在上级合计中。

## 匿名算例

某次视频生成合计为 **93.225 CNY**，其中已经包含 **Vidu 0.875 CNY** 和 **Duix 92.35 CNY**。另有配音 **0.11456 CNY**，因此已知总额为：

```text
93.225 + 0.11456 = 93.33956 CNY
```

图片生成费用尚未知，应保持 `null` 并注明“不含图片”。此前把已包含的 Vidu 0.875 再加一次得到约 94.2 CNY，是典型的上级合计与子项重复计费。对账时先画清包含关系，再求和。

账单和案例不得保存真实密钥、仍有效的签名 URL 或可识别的生产数据。
