# 共享制作契约

所有阶段共同遵守本契约；阶段技能只补充各自的产物和验收门。

## 事实与素材

- 功能结论必须来自软件源码、路由/API 契约、可复现页面行为、现有脱敏截图或用户明确提供的材料。无法验证的内容标为“待确认”或“演示设想”，不得写成已上线能力。
- 记录证据路径、页面或符号、观察日期、适用版本和限制。截图只能证明截图中可见状态；代码存在不等于生产已部署。
- 端口可达只证明传输层连通，不能证明视频可播放、帧可解码、音频存在或业务功能正常。视频能力需实际探测媒体流或解码帧。
- 不复制生产账号、基础设施地址、密钥、签名 URL、明文业务数据或其他生产数据。演示画面使用脱敏或合成数据，并明确其性质。
- 不让图像或视频模型重绘需要阅读的软件界面；界面应来自真实截图或录屏，主持人作为独立层合成。

## 模型和来源边界

- 图片模型只产出静态图像，不能据此声称已经生成连续动作、时序一致性或口型同步。
- 人物图、动作视频、TTS 和口型同步分别记录实际供应商与模型。使用 Moark 调度 Qwen、Vidu、Duix 等服务时，按实际后端标注，不能统称为 GPT 或 OpenAI。
- 口型视频必须由该段最终旁白驱动。用另一版旁白生成的旧视频，即使时长相近，也不能标记为同步；备用片段必须披露并在清单中设置 `lip_synced: false`。
- Duix 单段不超过 60 秒；经验默认按 40 秒左右切分，可根据停顿和服务实测调整。切分点应在自然语义边界，并保留可核对的段号。
- 五分钟目标以最终旁白的实测时长为准。优先压缩讲稿、删减重复信息和调整镜头，不用全片统一 1.4 倍速掩盖超时；任何变速都需试听并在清单记录。
- 抠像中间件交付带 alpha 的 WebM 或其他经验证支持透明通道的格式。MP4 用于完成背景合成后的最终分发，不把普通 MP4 宣称为透明素材。

## 外部任务与费用

- 提交前确认用户已授权该供应商、该请求和该预算。先用样片验证人物、声音或口型，再扩展整片。
- 每次提交必须使用唯一记录文件保存请求摘要、`task_id`、供应商、模型、币种、费用估算、时间和结果状态；记录不得包含密钥或仍有效的签名 URL。
- HTTP 超时或轮询超时不代表供应商没有执行。先查原任务状态，禁止盲目重复提交。
- 所有轮询都同时设置最大次数和墙钟超时，支持取消，使用有上限的 backoff，并定期报告进度。

## 本地执行

- Windows 上只使用 PowerShell 7，并先核对 `$PSVersionTable.PSVersion`。
- 文件枚举、搜索、批处理和重试都设置最大项目数与墙钟时限；禁止从盘符根目录、用户目录或 Program Files 做递归发现。
- 工具发现依次使用 `Get-Command`/`where.exe`、项目配置和已知固定路径。不要猜测工具名称或安装未经授权的依赖。
- 记录本任务启动的长时进程 PID、开始时间、命令行和父进程。成功、失败、取消或超时后，只清理经核实属于本任务的进程树和临时文件。
- 临时目录必须是本任务创建的专用目录，并在 `finally` 或等价路径清理；不清空共享临时目录，不删除交付物。

## 凭据

凭据只通过统一工具的 `credentials set/status` 管理，或通过受支持的隐藏输入临时传入。不得把密钥放入命令行、请求 JSON、任务记录、仓库、日志或最终报告。`status` 只报告是否配置，不显示秘密值。
