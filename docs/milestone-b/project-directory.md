# MPS 项目目录契约

`project.mps.json` 是新项目的根文件，采用 UTF-8、`format: mps.project` 和 `schema_version: 1`。当前最小实现保存项目身份、名称、创建时间、素材引用及素材哈希外发预检授权；时间线、会话及完整预算授权结构将在相应里程碑扩展。现有 CLI 的 `manifest.json` 是独立旧格式，仍按原入口读取，不被新根文件覆盖。

| 路径 | 用途 | 保留与清理 |
| --- | --- | --- |
| `assets/source/` | 用户导入的原始录屏、截图、音频与允许复制的源码证据 | 只读保留；不能随缓存清理 |
| `assets/generated/` | 生成后经校验的图片、配音、视频等正式资产 | 保留来源及任务引用；不能随缓存清理 |
| `cache/` | 可从源素材和项目状态重建的代理媒体、波形、缩略图 | 按后续缓存策略有界清理 |
| `records/` | 任务摘要、费用与阶段记录 | 只允许白名单字段；不保存原始供应商响应 |
| `sessions/` | 多条制作会话的本地记录 | 共享同一个根文件中的素材和时间线 |
| `versions/` | 自动快照和用户命名版本 | 数量与体积上限在“原子保存与版本”任务实施 |
| `delivery/` | 成片、字幕、报告与可重开交付内容 | 用户确认后管理，不作为临时文件 |

所有项目内引用使用 `/` 分隔的相对路径。解析时拒绝盘符、URL、`..`、空路径段、查询参数、重解析点和越出项目根目录的路径。素材暂时失联不会删除项目引用；复制或移动整个目录后，项目从新根重新解析。外部原件若未复制入项目，由后续素材索引以明确的外部引用管理，不伪装成可移植项目内路径。

根文件的当前模型包含身份、素材引用和精确外发授权，不提供凭据、签名下载 URL 或原始响应字段。授权仅保存提供商、账号别名、能力、用途、素材 ID、素材哈希及到期时间；项目默认没有授权。未知字段读取时明确报错，避免后续保存时静默丢失；格式迁移将显式处理版本升级。项目根文件通过临时文件替换写入，完整版本快照和崩溃恢复属于“原子保存与版本”任务。

离线回归在 `tests/VideoProduction.Tests` 中创建本地项目、复制文件并移动目录，核对素材相对路径、失联引用和越界拒绝；另检查无授权、跨提供商、跨账号、用途变化、内容变化和授权过期时的拒绝。测试不访问网络或付费服务。
