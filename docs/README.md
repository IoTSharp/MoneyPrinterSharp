- `development.md`：MoneyPrinter# 独立项目的开发入口、已验证范围与后续工作。
- `evidence-and-disclosure.md`：功能证据、演示数据、模型来源和备用素材披露口径。
- `media-and-sync.md`：时长、分段、alpha、口型和媒体探测要求。
- `cost-accounting.md`：任务号去重、币种分开、未知值与包含关系。

这些文档只描述本仓库的技能契约；供应商实时接口以当前官方文档和 CLI `--help` 为准。
