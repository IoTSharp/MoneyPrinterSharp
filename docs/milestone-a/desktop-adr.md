# ADR-A01：桌面宿主采用 Avalonia + AtomUI

状态：**技术栈已选定，平台与媒体能力仍待实机验收**。日期：2026-09-29。第一版产品目标仍为 Windows 10/11；采用跨平台 UI 不等于其他平台的录屏、凭据、安装和媒体链路已经受支持。

## 决定

桌面工作台使用 C# / .NET 10、Avalonia 12.1.2 和 AtomUI.Desktop.Controls 6.2.1。应用通过 `UseAtomUIPlatformDetect().WithAtomUIDefaultOptions()` 启动，并在应用初始化时注册中文语言与桌面控件；原生 Avalonia 控件使用 FluentTheme 补齐模板。项目、媒体、代理和费用状态保留在独立 C# 领域层，UI 只消费同一份项目事实。FFmpeg/FFprobe 仍负责媒体处理，不增加 JavaScript 业务运行时。

选用该组合是为了在保留 .NET 开发与既有 CLI 兼容性的同时，获得可跨桌面平台使用的 UI 基础及完整的控件主题。用户明确要求替换此前的 WPF 视觉方案，并建议评估 [AtomUI Gitee 仓库](https://gitee.com/chinware/atomui)。当前原型从 NuGet 引用已发布二进制包，不复制第三方源码进本仓库。AtomUI 包附带 LGPL-3.0 许可证；未来分发须保留许可证与第三方声明，并核对 LGPL 对链接、替换库及修改库源码的具体义务。当前没有修改 AtomUI 源码，也没有发布安装包。

## 原型与证据

`prototypes/AvaloniaWorkbench` 是独立、无付费接口的桌面交互原型。它保留左项目/会话/技能、中对话、右预览与五轨时间线，并提供七种状态、16:9/9:16 预览框、模拟播放、片段拖动/分割/裁短/移动/撤销。窄窗口菜单仍能进入项目、会话及技能。预览使用本地合成演示图片，不代表真实软件画面或成片。

在 Windows 11 与 .NET SDK 10.0.400 上，原型构建零警告；`--smoke` 验证七种状态、会话切换、窄窗入口及时间线编辑，退出码 0；`--capture` 离屏渲染 1360×840、820×680 和 760×620 PNG，并对图像进行人工走查，输入控件、预览和时间线均可见。可复现命令见原型 README。以上只证明本机原型可运行，不能证明 Windows 10、macOS、Linux、真实预览/录制、高 DPI 或安装包性能。

此前 `prototypes/DesktopWorkbench` 的 WPF 原型曾完成相同尺寸的构建、烟测和截图走查。它保留为历史对照，不再是桌面产品的优先实现路线。WinUI 3 也仅作为 Windows 专用参考，不再要求为其构建同规模原型后才能开始共享核心开发。

## 约束与待验收项

| 事项 | 当前判断 | 仍需证据 |
| --- | --- | --- |
| UI 跨平台 | Avalonia/AtomUI 提供 Windows、macOS、Linux 桌面运行基础；本仓库只在 Windows 11 运行了原型 | 各平台启动、字体、拖动和高 DPI 实测；V1 对外支持范围另行决定 |
| Windows 最低版本 | 目标暂定 Windows 10 22H2 x64 | 干净系统安装、启动、升级、卸载及录屏/系统音频检查 |
| 视频预览 | 目前仅静态合成画面和模拟播放时钟 | 1080p 双画幅、音画同步、定位延迟及 CPU/GPU 占用 |
| 录屏 | 应封装 Windows 捕获与音频服务，和 UI 宿主解耦 | 窗口、屏幕、区域、麦克风、系统音频的真实捕获与取消 |
| 安装与自动化 | 可为各桌面系统分别发布 .NET 应用 | 自包含安装包、无 SDK 启动、辅助功能与 100%/150%/200% 缩放 |

阶段 A 的桌面选型已收敛，但上述验证和需求矩阵审阅尚未完成；不能据此宣称阶段 A 全部通过。
