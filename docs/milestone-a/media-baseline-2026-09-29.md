## 验证和资源回收

独立工程构建为 0 警告、0 错误；`--help` 正常返回。正式测量前先以 `--preflight-only` 运行 160×90、10fps、两帧样本，其生成与完整解码通过；正式测量也再次执行相同预检。预检曾发现已退出进程的托管内存属性读取异常，修正为持有句柄的 Windows API 后重建并通过预检，随后才进行上述正式批次。

正式批次总计 24 个子进程，均串行执行并已退出；总时限八分钟、每阶段九十秒、进程数上限三十二，支持 Ctrl+C。每个子进程留有 PID、UTC 创建时间、父 PID、完整命令参数和最终退出状态。成功报告的 `AllChildProcessesExited` 与 `TemporaryMediaRemoved` 均为 `true`；合成源和输出媒体仅在本次唯一临时目录产生并已删除，聚合报告与本地审计日志作为验证证据保留。没有常驻服务或付费调用。

此次结果支持 [非功能基线](nonfunctional-baseline.md) 中同机回归候选阈值，不直接锁定产品阈值。仍缺第二套代表性机器、Windows 10、真实 GUI 冷启动/定位预览/拖动提交/高 DPI 交互、真实录屏与音频采集、多轨混合、五分钟规模及长时间稳定性数据。当前只能确认本机的这组离线合成样本已正确处理，不能标记里程碑 A 整体完成。
