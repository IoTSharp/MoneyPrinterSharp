## 可重复验证

本轮环境：PowerShell 7.6.6、.NET SDK 10.0.401 / runtime 10.0.12、Windows 11 25H2。构建使用 `--disable-build-servers -m:1 -p:UseSharedCompilation=false -nr:false`；运行外部宿主设置时限并记录 PID、创建时间、完整参数和父进程，结束后检查本次进程树。

| 范围 | 验证与结果 | 限制 |
| --- | --- | --- |
| CLI 与离线安全回归 | 测试工程构建 0 警告/0 错误，原费用/清单回归和上述安全用例退出码 0 | 无网络/凭据/计费请求；不是生产上传端到端 |
| Avalonia 交互原型 | 七场景、双画幅、片段分割/移动/裁短/完整撤销、共享会话、窄窗菜单通过 | 内存模拟数据 |
| 布局与离屏 DPI | 1360×840、820×680、760×620 × 100/150/200%，九组控件边界/区域不重叠/PNG尺寸及像素检查通过 | 不改变系统 DPI，不验证真实输入命中或跨显示器行为 |
| 单机媒体 | 横竖 1080p、15 秒、H.264/AAC，分别完整解码 450 帧；转码约 4.0–4.1 秒 | CPU 两线程、单机合成样本、无 UI/录屏/多轨 |

本轮另按用户对配色的反馈应用 `impeccable` 的 Operate/quieter 原则：中性浅灰/白色操作区、石墨预览、单一蓝色交互强调和低饱和轨道色。保留三栏及所有原型入口，对话消息改为平面段落，控件统一资源。初次视觉复核发现中文字体与占位文字可读性问题；显式设置中文系统字体，并修正 Fluent `TextControlPlaceholderOpacity` 默认 0.5 的资源覆盖。最终对实际 `ShapedTextRun` 核对：对话正文、轨道和占位文字均使用 Microsoft YaHei UI；占位模板实际 `Foreground=#5D6672`、`Opacity=1`，并纳入九组合断言。文本样式与实际字形分别核对，不用 XAML 声明替代结果。
