# 安全与数据流边界

## 数据去向

| 数据 | 本地位置/处理 | 可外发条件 | 删除与日志 |
| --- | --- | --- | --- |
| 源码与运行页面 | 用户指定路径；只读索引/允许的截取 | 项目授权明确列出提供商、路径范围、用途 | 原件由用户管理；日志仅记范围 ID 和哈希 |
| 录屏、截图、麦克风/系统音频 | 项目 `assets/source` 或外部引用 | 文件/片段级白名单，发送前展示摘要 | 不随缓存清理；删除需检查引用并由用户操作 |
| 提示词与讲稿 | 会话及阶段产物 | 仅授权的文本范围及目标账号 | 本地保留可删除；日志不记原文 |
| 生成资产与代理缓存 | `assets/generated`、`cache` | 再外发须单独检查授权范围 | 缓存可重建且有上限；不删除原资产 |
| 凭据 | Windows Credential Manager | 仅目标提供商已验证 HTTPS 主机 | 不进入项目、命令行、Git、日志或崩溃摘要 |
| 签名下载 URL | 内存中完成有界下载 | 只用于指定下载主机且不携带 Bearer | 不落盘，不记完整 URL；超时后清除内存引用 |
| 供应商原始响应 | 有界内存解析 | 不作为项目产物 | 仅白名单提取任务号、状态、金额、币种、输出哈希；原文不入库 |
| 任务/费用记录 | `records` 与项目账本 | 交付时只带脱敏摘要 | 记录稳定任务号、指纹、授权 ID、时间和未知状态 |
| 临时渲染文件 | 本次任务专属目录 | 无 | 仅清理当前 PID/创建时间/命令行匹配的进程树和任务临时文件 |

## 执行规则

1. 项目默认禁止外发。授权是 `project + provider + account_alias + model + capability + asset/source/text scope + purpose + cumulative budget + expiry` 的交集；超出任一项停止任务。
2. 只读目录发现与账号状态查询可以先执行；可能计费的最小探测需独立授权。新模型、新供应商或新增素材范围不能继承旧授权。
3. API 基址必须是无用户信息的 HTTPS 绝对地址。Bearer 只发给配置并校验的主机，禁止认证重定向；代理和下载请求分别处理。
4. 响应脱敏采用字段白名单，不对原始 JSON 做“替换后保存”。错误保留类别、HTTP 状态和可恢复操作，不保留原始消息、响应头、提示词或签名参数。
5. 崩溃/超时后的提交状态记未知并保留预算预留。存在稳定任务号时先查旧任务；无任务号时人工核对，不重新发起付费 POST。
6. 导出包扫描凭据字段、签名 URL、绝对本机路径和未获许可的媒体。用户删除项目时提示外部原件不在删除范围。

## 里程碑 A 可执行契约与验证

`src/VideoProduction/ProjectOutboundAuthorization.cs` 提供不可变的授权、外发意图和可注入传输契约。授权按项目、提供商、账号别名、锁定模型、能力、用途、累计预算快照及到期时间求交；每个素材或文本引用必须匹配完整项目逻辑路径，源码引用还必须落在明确的行号区间内。默认拒绝，空范围与无授权都不能发送。每侧最多64条引用、最多4096次范围比较、路径最多32段；校验最多5秒，发送等待最多3分钟且不超过剩余授权时间，支持调用方取消。公开入口使用宿主 UTC 时间。

逻辑路径拒绝绝对路径、`..`、反斜线、编码路径、备用数据流、尾随空格/点和 Windows 设备名。这一阶段验证的是**不可变内存意图的交集契约**，不是对实际上传字节的授权证明。宿主以后必须从可信项目状态和账本构造授权及预算快照，绑定打开的文件句柄、哈希、实际截取的源码行，并处理符号链接/重解析点及检查与使用之间的替换；不能直接采信代理自报的路径、预算或素材列表。当前契约只检查快照，不实现预算预留、授权消费或并发锁；后续集成须接入共享预算机制。传输适配器必须遵守取消令牌并使用同一已绑定的字节。旧 `moark submit/poll` CLI 尚未接管该项目授权边界，因此不能将此契约标为产品全局外发控制已完成。

`src/VideoProduction/ProviderResponsePolicy.cs` 是 Moark 实际提交和查询共同使用的白名单提取路径：只采纳格式有效且未原样回显当前凭据的任务号、已知状态、数字费用、受限币种和 HTTP 状态；错误码由本地固定类别产生。原始 JSON、供应商错误消息、提示词、密钥字段和签名 URL 不进入任务或共享预算记录。媒体下载地址仍仅在原有内存路径使用。

`tests/VideoProduction.Tests/SecurityContractTests.cs` 接入既有离线测试入口：

- 27个拒绝负例覆盖默认拒绝、全部授权维度、预算、素材/源码范围、65条引用/白名单超限、路径穿越与 Windows 路径歧义；每例用内存传输断言零发送。
- 1个合法交集确认原意图只发送一次，预先取消确认零发送，发送中取消确认协作式模拟传输结束且无残留任务。
- 7个供应商响应场景通过生产共用提取策略、`JsonFiles.Write` 任务/预算台账和实际 `MoarkClient.Print`，检查状态/金额往返正确，密钥、签名 URL、错误消息及原始字段标记均不进入落盘文件或输出；其中任务号不匹配必须拒绝并保留原费用/币种/状态。
- 测试总时限45秒，各安全批次最多15秒；临时文件位于本次测试独占目录，`finally` 只删除两个明确创建的文件并非递归删除目录。

运行方式：`dotnet run --project tests/VideoProduction.Tests/VideoProduction.Tests.csproj -p:UseSharedCompilation=false`。执行结果以当前构建和测试输出为准；这些用例不读取凭据、不访问网络、不提交付费请求。

后续里程碑 C/D/I 仍须验证实际素材与文件句柄绑定、所有提供商适配器和重定向边界、桌面外发确认、导出包扫描及崩溃日志；本次离线契约与记录验证不替代这些生产验收。
