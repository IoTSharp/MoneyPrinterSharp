# 非功能基线草案

这些是 V1 工程上限的初值，配置可收紧，不能设为无限。性能目标须在桌面原型和代表性媒体上测量后锁定；目前没有实测数据，不能将下表当作已达标结果。

| 操作 | 次数/资源上限初值 | 墙钟上限初值 | 取消与恢复 |
| --- | --- | --- | --- |
| 单次录制 | 1 路画面、麦克风和系统音频各 1 路；单文件 20 GiB | 2 小时 | 停止后探测；异常只清理本次录制临时文件，保留可恢复文件 |
| 单次导入 | 500 个文件，项目索引媒体合计 100 GiB；单源最长 12 小时 | 每文件探测 30 秒，总批次 30 分钟 | 逐项取消；已索引条目保留，损坏文件不阻断整批 |
| 时间线 | 64 轨、10,000 片段、1,000 字幕/画幅，成片目标 15-300 秒 | 单次编辑验证 2 秒 | 操作失败不改已保存版本 |
| 代理一轮 | 最多 20 工具调用、8 次模型往返、累计 30,000 输入/输出令牌 | 30 分钟 | 取消后保留任务号、预算和阶段状态；无自动重复付费提交 |
| 异步任务查询 | 最多 300 次，间隔 1-60 秒 | 30 分钟 | 超时标记未知/待查；重开只查询既有任务 |
| 单次 FFmpeg 渲染 | 同时 1 个主渲染，临时空间预留估算输出的 2 倍且至少 2 GiB | 60 分钟 | 记录 PID、创建时间、命令行、父进程；仅清理本次树 |
| 下载 | 单文件 512 MiB、最多 8192 块 | 180 秒 | 仅删除本次 `.part`，旧任务和远端输出保持可查询 |
| 项目版本 | 自动快照最多 100 份或 2 GiB，以先到为准；命名版本不自动删除 | 单次原子保存 10 秒 | 最后完整版本可重开；磁盘不足不覆盖旧版 |

常规三栏布局以约 1110 逻辑像素宽度为切换点；当前原型包含 760×620 的离屏布局检查，更窄时左侧导航折叠。最低可操作窗口仍待人工交互验收，右侧预览/时间线改为可切换工作区仍是目标设计。DPI 验证覆盖 100%、150%、200%。测试机需记录 Windows 版本、CPU、内存、GPU、媒体编码、项目资产与片段规模，采集冷启动、定位预览、拖动提交、1080p 导出时间及峰值内存。性能阈值在两套代表性机器实测后制定，不能以当前开发机单次结果替代。

## 2026-09-30 本机探索性测量

本节是单台开发机的离线基线，不是 Windows 10/11 通用阈值，也不是成片验收。测量机为 Windows 11 家庭中文版 10.0.26200（64 位）、i9-13900HX（24 核/32 线程）、可见内存 33,231,568 KiB（约 31.69 GiB）；显卡为 Intel UHD Graphics、RTX 4070 Laptop GPU，另有虚拟显示适配器。工具为 .NET SDK 10.0.400、FFmpeg/FFprobe 8.1.1、PowerShell 7.6.6。以下 `libx264` 测量使用 CPU 编码，不代表 GPU 加速结果。

输入分两类：Avalonia + AtomUI 原型内存中的 5 轨、7 片段演示状态；FFmpeg `testsrc2` 动态测试画面加 440 Hz 合成音调，分别为 1920×1080 和 1080×1920、30 fps、15 秒。仓库 `examples/demo-mps` 原样本为 1280×720、4 秒、H.264/AAC，仅用于确认其不满足 V1 最短时长和 1080p 测试条件；未把它作为 1080p 测量输入。两种新样本均只写入系统临时目录，测后删除。

| 测项 | 本机结果 | 解释 |
| --- | --- | --- |
| 原型 `dotnet build --no-restore` | 7.475 秒，0 警告/0 错误 | 构建时间，不是启动延迟 |
| 原型进程启动至 `--smoke` 退出 | 11.255、5.409、2.817 秒；中位 5.409 秒；采样峰值工作集 206.9、208.6、199.3 MiB | 首次运行紧跟构建；系统缓存状态未控制，不能称为冷启动或首帧时间 |
| 16:9 合成 H.264/AAC 编码 | 3.032 秒；10,198,142 字节；采样峰值工作集 1,164.3 MiB | `libx264` 8 线程、`veryfast`、CRF 23，单次测量 |
| 9:16 合成 H.264/AAC 编码 | 3.289 秒；11,012,160 字节；采样峰值工作集 1,127.7 MiB | 相同编码参数，单次测量 |
| 16:9 完整解码到空输出 | 0.463、0.445、0.475 秒；中位 0.463 秒；采样峰值 139.2-142.2 MiB | 视频和音频均解码，不含编辑、合成或写 MP4 |
| 9:16 完整解码到空输出 | 0.396、0.376、0.373 秒；中位 0.376 秒；采样峰值 142.3-142.6 MiB | 同上 |

FFprobe 对两个输出均确认 15.000 秒、H.264 450 帧、AAC 48 kHz（704 个音频帧）；随后 `ffmpeg -xerror` 完整解码退出码均为 0。编码的工作集每 100 ms 采样，解码每 10 ms 采样，数值可能低于真实瞬时峰值。计时是子进程从启动到退出的墙钟时间；未控制后台负载，短任务的数据仅用于后续同机回归比较。

复现命令（在仓库根目录的 PowerShell 7 中运行；每次使用新的临时文件名）：

```powershell
dotnet build prototypes/AvaloniaWorkbench/AvaloniaWorkbench.csproj --no-restore --disable-build-servers -p:UseSharedCompilation=false -v:q
dotnet prototypes/AvaloniaWorkbench/bin/Debug/net10.0/Mps.AvaloniaWorkbench.dll --smoke

$sample = Join-Path $env:TEMP ("mps-perf-" + [guid]::NewGuid().ToString('N') + '.mp4')
if (Test-Path -LiteralPath $sample) { throw '临时路径已存在' }
ffmpeg -hide_banner -v error -f lavfi -i 'testsrc2=size=1920x1080:rate=30:duration=15' -f lavfi -i 'sine=frequency=440:sample_rate=48000:duration=15' -c:v libx264 -threads 8 -preset veryfast -crf 23 -pix_fmt yuv420p -c:a aac -shortest -n $sample
ffprobe -v error -count_frames -show_entries 'format=duration,size:stream=codec_name,width,height,r_frame_rate,sample_rate,nb_read_frames' -of json $sample
ffmpeg -hide_banner -v error -xerror -i $sample -f null NUL
[IO.File]::Delete($sample)
```

竖屏仅将 `testsrc2` 的 `size` 改为 `1080x1920`。表中计时与内存由 `ProcessStartInfo.ArgumentList` 启动进程、`Stopwatch` 计时和 `WorkingSet64` 定时采样取得；构建、烟测、编码、探测、解码的单进程最长等待分别为 180、45、120、30、30 秒，超时取消本次创建的进程树。命令行不含凭据。以下为计入表中测量的进程记录；时间为 UTC，同一组的命令行采用上方对应命令，临时文件名分别为 `mps-perf-20260930-a39e2f.mp4`（横屏）和 `mps-perf-20260930-b42f3d.mp4`（竖屏）。

| 命令 | PID（父 PID） | 创建时间 UTC |
| --- | --- | --- |
| 构建 | 43260（50524） | 01:51:35.800 |
| `--smoke` 1/2/3 | 43700/48844/17864（均 59360） | 01:52:02.309 / 01:52:13.654 / 01:52:19.061 |
| 横屏编码 / FFprobe | 55668（17208）/ 59104（49016） | 01:53:29.799 / 01:53:44.459 |
| 横屏解码 1/2/3 | 27644/49096/37592（均 25268） | 01:54:24.088 / 01:54:24.560 / 01:54:25.007 |
| 竖屏编码 / FFprobe | 53260（50504）/ 59764（51864） | 01:54:39.680 / 01:54:51.217 |
| 竖屏解码 1/2/3 | 55104/48892/16452（均 60384） | 01:55:04.299 / 01:55:04.703 / 01:55:05.081 |

仅在这台机器上，可把原型 `--smoke` 退出不超过 20 秒、采样工作集不超过 300 MiB，以及上述 15 秒合成片单次 FFmpeg 编码不超过 15 秒、采样工作集不超过 2 GiB，作为后续回归的宽松预警线；超线需复测与分析，不能据此直接判产品不合格。解码建议以同机中位时间跟踪，不因不足半秒的三次结果设发布阈值。

**未满足非功能基线完成判据的部分**：当前原型无真实媒体预览、定位或成片导出，`--smoke` 也没有逐操作耗时，因此尚无用户感知冷启动、定位预览、拖动提交、1080p 多轨导出和长时间运行数据。尚未在第二台代表性设备或 Windows 10 测量，也未覆盖 100%/150%/200% DPI 下的性能。待生产工作台及媒体链路可运行后，用明确资产规模在两台目标机器测量这些操作及峰值内存，再制定 V1 性能阈值；不能将本节的合成 FFmpeg 结果代替该完成判据。
