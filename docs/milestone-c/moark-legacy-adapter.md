# Moark 既有请求的统一适配兼容

`MoarkProviderAdapter` 将仓库已有的四类请求接入统一的任务提交、状态查询和错误映射接口。`VideoProduction moark submit|poll` 继续使用原参数、版本 1 任务记录、`.moark-budget.json` 目录预算台账、请求指纹与文件锁；本轮没有读取账号凭据、访问真实供应商或提交付费请求。

| CLI 用途 | 请求模型 ID | 能力 | 原请求路径 |
| --- | --- | --- | --- |
| `image` | `qwen-image-2.0-pro` | 图片生成 | `/images/generations` |
| `voice` | `Qwen3-TTS` | 语音合成 | `/async/audio/speech` |
| `motion` | `ViduQ2-Turbo` | 视频生成 | `/async/videos/generations` |
| `lipsync` | `Duix-Avatar` | 口型同步 | `/async/videos/audio-video-to-video` |

这些映射来自已有源码与本地兼容契约，契约版本为 `moark.legacy-offline.v1`。它们不证明当前模型目录、账号权限、限制、价格或生产接口可用；这些事实继续为未知，真实发现和授权实测属于后续工作。

统一提交请求只带账号别名、模型、能力、指纹和估算。适配器在内存中绑定已经验证的旧请求与文件句柄，拒绝跨账号、跨模型、跨能力、不同指纹、币种或估算的替换。目录预算仍在旧 CLI 的文件锁中预留；超时、取消、无任务号或费用未知都保留占用，不自动重发。

同步图片没有供应商任务号。统一接口以 `mps-image-<fingerprint>` 表示这次同步结果，仅作为本地终态投影；原记录的 `task_id` 保持空值，不能把该 ID 发送到供应商查询端点。图片输出仍由旧 CLI 保存并记录 SHA-256。异步任务继续使用供应商稳定任务号，重开先查询原任务；配音的输出查询也校验原任务号。

每次提交或查询默认最多等待三十秒，适配器允许配置到五分钟以内。轮询总截止时间同时覆盖查询和延迟。忽略取消的迟到响应被观察并释放，不能回写已经返回的记录。仓库尚无已核实的取消端点，因此统一取消接口返回未知/不可用，不发送请求，也不声称供应商任务已取消。

`IMoarkTransport` 与 `MoarkClientRuntime` 允许完全离线替换传输和凭据读取。`MoarkAdapterCompatibilityTests` 覆盖四类 CLI 请求、精确指纹预像、multipart 固定文件名、旧记录恢复和输出复用、跨记录去重、未知费用、账号/模型锁定、未知状态、输出任务号校验、超时不重提与迟到响应释放。测试只写独占临时目录中的本地小样例并按已登记路径清理；统一构建和测试结果由本轮验证记录提供。
