# 实测证据与授权小额探测契约

本批仅实现共享 C# 契约与离线假适配器验证入口。没有请求 Moark、sonnet.vip 或其他供应商，没有读取账号/凭据，没有真实价格或生产调用证据；模型目录与桌面界面的证据展示仍需后续接入。

## 证据层级

`MpsMeasurementEvidence` 将四种事实分别记录：

| 等级 | 能证明的事实 | 成本与失效约束 |
| --- | --- | --- |
| `ReadOnlyMetadata` | 公开或账号只读元数据列出某项能力 | 调用次数为零，无生成任务号；价格可保持未知。 |
| `FreeMinimalCall` | 最小调用通过或失败 | 通过必须有已确认零成本；零金额估算不证明免费。 |
| `BillableMinimalCall` | 可能计费的最小请求结果 | 明确保存估算、实付或未知成本；超时不证明未扣费。 |
| `RealMaterialSample` | 用户许可素材在某次制作中的结果 | 与最小请求分开保存；离线样片不证明真实供应商可用。 |

每条证据保存提供商、账号、模型/来源版本、能力、来源、观察时间、可选到期时间、输入指纹、任务号、成本、限制和失效条件。`Passed` 仅在观察时间之后和到期之前有效；未通过、超时、取消和未知状态不能展示为通过。账号、模型/接口版本、价格/限制变化时，调用方必须按保存的失效条件重新评估。证据与成本字段禁止凭据、签名下载地址和原始响应字段。

## 探测计划

`MpsProbeAuthorization` 在执行前保存项目、提供商、账号别名、模型、能力、等级、请求摘要、单次金额上限、累计预算、币种、最大次数及授权期限。`MpsAuthorizedProbePlan.Preflight` 默认拒绝未授权、失效、摘要不一致、未知费用、币种不符、单次/累计超额、项目硬预算不足和已有未解决任务。相同输入指纹只能读取或查询已有结果；要明确安排不同探测，必须使用不同的已授权指纹且保留次数和金额约束。

`Begin` 在共享恢复仓库锁内再次预检、登记意图和预留预算。任务号返回后调用 `MpsBudgetLedger.BindTaskId` 原子绑定供应商稳定任务号；后续对账按 `provider + task_id` 去重。关闭时保存 `MpsProbePlanSnapshot`；重开恢复预算占用，不能通过重开清零授权次数、已花金额或未知费用。

`MpsAuthorizedProbeCoordinator` 复用 `ProviderAsyncTaskCoordinator`。项目侧必须提供外发/模型锁定预检，以及提交前持久化回调。回调在计划意图和异步任务意图均已登记后执行；落盘失败时不会调用提交适配器。实际提交、查询和取消单操作默认最多等待 30 秒，允许配置至 5 分钟；轮询沿用次数、总墙钟截止时间和取消令牌边界。超时、用户中止、终态费用未知保留原任务与未知预算占用，禁止自动重提。

供应商若实际费用超过用户单次/累计授权，或返回不同币种，结果保留 `Unknown` 和已观察费用并要求人工对账。预算可容纳时保留较大的未知占用；项目硬预算不能容纳时保持原预留并在恢复记录中保留超额实付观察。此情况不得标记为“授权金额内通过”，也不得自动提交下一条探测。

## 离线验证入口

统一测试入口应调用 `MeasurementEvidenceTests.Run()` 与 `AuthorizedProbePlanTests.RunAsync(ct)`。测试使用本地内存对象和一个有 `Dispose` 清理路径的假适配器；覆盖四等级、免费/未知成本、过期/未授权、次数与金额上限、并发意图、稳定任务号对账、提交前落盘、超时/取消、重开恢复、费用超额、快照篡改和终态迁移。测试不创建外部进程或临时文件，不发送供应商请求。

路线图 #003 的界面展示和 #004 的真实授权探测尚无外部验收证据，不能仅凭这些核心契约移除对应条目。
